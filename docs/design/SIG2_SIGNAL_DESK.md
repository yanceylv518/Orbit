# SIG-2 信号台与人工留痕（完成实现说明）

> 本文最初记录 2026-08-14 的第一阶段实现，现已按 `PROJECT_PROGRESS.md` 后续扩充并冻结的 SIG-2 正式契约补齐。正式验收仍以项目进度中的逐项清单为准。

## 1. 目标与边界

SIG-2 把 SIG-1 已落盘的信号变成可供人工判断和复盘的工作台。它不改变信号定义、不修改模拟单、不接管 Binance 下单，也不把人工录入伪装成交易所成交。信号核心零账户依赖；可选绑定专用子账户后，账户同步会读取 Binance 成交并自动配对。

页面只做三件事：

1. 展示当日全部信号及其独立模拟结果；
2. 记录用户对候选信号的“我做了 / 我跳过”决定，并在可选账户同步后自动配对真实成交；
3. 展示运行健康、冻结参数、推送状态和纪律状态；三本账只保留试算，正式比较归 SIG-3。

## 2. 数据与只追加约束

- SIG-1 信号账继续使用 `ORBIT_SIG1_SIGNAL_SERVICE_V1`，SIG-2 只读并校验其 manifest 和 SHA-256 哈希链。
- 人工决定与人工成交写入独立的 `ORBIT_SIG2_INTERACTION_LEDGER_V1` 哈希链，默认目录为 `var/signals/sig2`。
- 决定和成交只允许追加，不允许覆盖。相同信号只能登记一次决定和一笔完整人工成交。
- 接口不返回操作者身份和上游请求标识。
- SIG-1 未部署、账本缺失或哈希校验失败时，页面显示真实健康状态，不生成演示数据。
- Pushover Token/User Key 经现有凭证库加密后只把引用写入 SIG-2 账本；API 只返回是否配置和指纹，不回显引用或明文。

## 3. 四条硬约束

1. **必须带止损**：选择“我做了”时必须给出有效止损；多单止损低于进场价，空单止损高于进场价。
2. **禁止亏损加仓**：一个信号只允许一笔人工成交，不允许覆盖或登记第二笔成交。
3. **止损后冷静期**：同交易对、同方向在止损后的 4 小时内不得再次登记“我做了”，页面显示解禁时间。
4. **禁止计划外交易**：只能关联 SIG-1 当日正式候选；被每日候选上限截断的信号保留模拟记录，但不能登记人工参与。

连续 3 笔亏损或当日累计达到 `-3R` 时触发当日熔断。任何放宽请求只追加登记，最早 24 小时后生效；现阶段不提供绕过止损与禁止加仓的放宽入口。

## 4. 三本账试算（正式比较归 SIG-3）

| 账本 | 样本范围 | 收益来源 |
| --- | --- | --- |
| 全部信号模拟 | SIG-1 当日所有信号 | SIG-1 独立模拟单 |
| 我选择的信号模拟 | 人工标记“我做了”的信号 | 同一批信号的 SIG-1 模拟结果 |
| 我的实际成交 | 已补录完整进出场的人工成交 | 按人工进场、退出及登记止损换算 R |

三本账不相互覆盖。当前页面只提供试算可见性；正式口径、报告和验收属于 SIG-3。

## 5. 页面与图形

- 一级导航新增“信号”，内部包含“信号台”和“信号复盘”。
- 信号卡主视图将 K 线和成交量放在同一张紧凑图中；小箭头标记信号发生位置，进场线和止损线直接标注。
- 鼠标悬停单根 K 线可查看开高低收、涨跌幅、振幅和成交额。
- 旧信号若未保存图形快照，明确显示“该历史信号没有图形快照”，不反查当前行情冒充历史证据。
- 窄屏采用单列卡片和双列指标，不产生横向滚动。
- Pushover 深链使用 `#signals/{signal_id}`，打开后自动滚动并高亮具体信号。
- 信号页分为“信号台 / 信号复盘 / 网页预警”；网页预警从 SIG-1/SIG-2 真实事件账本投影扫描、行情、推送、账户和纪律异常，并区分“处理中 / 已恢复”。
- Pushover 凭证只在“账户”页面配置；信号台只读展示手机推送状态，不提供第二套凭证表单。

## 6. 接口

- `GET /api/signals?day=YYYY-MM-DD&limit=N`：读取信号台快照和三账复盘。
- `POST /api/signals/decisions`：追加 `TAKEN` 或 `SKIPPED` 决定。
- `POST /api/signals/pushover` 与 `/pushover/test`：安全保存并即时验证推送配置。
- `POST /api/signals/service`：控制后台扫描开关。
- `POST /api/signals/binding`：可选绑定成交对照子账户；与 TB4 活跃绑定冲突时硬拒绝。
- Binance 账户同步成功后自动调用成交配对；不能关联正式信号的成交写为计划外交易。

三个接口均要求管理员权限。SIG-2 不提供真实下单接口。
