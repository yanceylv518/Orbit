## 信号时刻的可观察差异

完整机器报告逐参数、逐出场输出 Top 10% / 中间 80% / Bottom 10% 的八项特征分位数、类别占比和组间均值差。RB-1 出场口径下四组较一致的现象：

- Top 10% 的相对成交量均值比 Bottom 10% 高约 0.23–0.42 倍。
- Top 10% 信号发生时，BTC 同观察窗收益平均更低约 0.17–1.26 个百分点。
- Top 10% 的 UTC 小时均值早约 0.70–0.88 小时。
- 跌幅更深在 16 根观察窗较明显（约 +0.82 至 +1.34 个百分点），32 根窗口差异较小（约 +0.09 至 +0.33）。
- 流动性层、上市年龄、三日量趋势没有跨四组完全一致的单一方向。

## 筛选力需求与突破族对照（v2）

筛选力需求曲线把事件按最终收益排序，依次剔除最差的 5%–60%，记录剩余均值；`k*` 是剩余均值首次超过 +0.3% 所需的最小剔除比例。它是事后视角下的任务难度下限，不是可执行收益。

- 超跌族 8 个“参数×出场”画像中，7 个的 `k*=5%`，1 个为 `10%`。
- 突破族 8 个冻结参数画像的 `k*` 全部为 `20%`。
- 因此在同一门 B 描述口径下，超跌族只需理论上避开较少的最差事件即可显著转正；突破族需要正确识别并避开约五分之一最差事件，筛选难度明显更高。
- v2 同时输出反向的“只保留最好 k%”均值曲线。突破族由冻结 R0 事件检查点复现；检查点不含路径 K 线，因此其最终收益/R、尾部、频率、筛选曲线和已有类别特征完整输出，MFE/R 与缺失的连续事前特征明确标为不可用，没有填造数值。
